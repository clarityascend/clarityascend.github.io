THE TOOLKIT

Two tools. See the data, then understand the code.

MVBU Chrome · Edge · VS Code

MultiValue Basic Utility

Run commands, call APIs and read file schema at full width in a browser tab. MVBU views data and never edits records.

  • Developer console — TCL/ECL at TERM 132,999, history, favourites, select lists kept between commands.
  • API calls — call catalogued subroutines with IN / OUT / IN-OUT arguments; XML sent as typed; dynamic arrays broken down by field, value and sub-value.
  • Analyst view — look up a record, find records step by step, see what's in a file. Plain language, no field numbers.
  • File schema — dictionary, layout and record views in one click.
  • Markdown output — every run saved, downloadable as .md or .zip.

Allowed-commands guard

Only LIST, SORT, SELECT, CT, COUNT and friends run by default. Everything else is blocked or needs confirmation.

Confirm on PROD

Per-profile confirmation before commands, API calls and compiles.

Secrets stay local

Passwords in macOS Keychain, Windows Credential Manager or Python keyring. SSL required.

Licence-friendly sessions
