This blog is about keeping MultiValue systems (Rocket UniVerse, UniData and other Pick-style databases) productive with modern tools, without rewriting them.

It is also home to two tools:

- [**MVBU**]({{ '/mvbu/' | relative_url }}), MultiValue Basic Utility, for Chrome, Edge and VS Code
- [**MVBA**]({{ '/mvba/' | relative_url }}), MultiValue Basic Analyser, for VS Code

See the [Modernization]({{ '/modernization/' | relative_url }}) tab to get started.

UniVerse and UniData are products of Rocket Software.
